# Kailash Datt Bhatt — Static Website

This is a free static website. It does not need a paid server.

## Preview locally
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create a GitHub account/repository.
2. Upload the contents of this folder to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide a free public URL such as `username.github.io/repository-name/`.

## Alternative free hosts
The same folder can be deployed to any static-site host that supports plain HTML/CSS/JS.

## Before publishing
- Review every biographical fact with Kailash Datt Bhatt.
- Replace or remove any photo he does not want public.
- Do not add a private phone number, home address, personal email, or other sensitive information.
- Once the final public URL is known, add that URL as the site's canonical URL and generate a sitemap.

## Search indexing
After publication, submit the public URL to Google Search Console and request indexing. Google decides whether to create or display a Knowledge Panel; publishing a site does not guarantee one.
